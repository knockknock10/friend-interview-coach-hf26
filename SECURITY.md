# Security

## Privacy model

Interview answers are sent to the local Ollama runtime when running the real application. The project does not require a cloud AI API or account.

The hosted challenge demo intentionally uses sample feedback and does not pretend to provide the private local model runtime.

## Reporting

Please do not open a public issue containing private interview answers, credentials, API keys, or other sensitive material. For a security concern, contact the repository owner privately through GitHub.
